
# 快速上手指南

## 5分钟快速开始使用RAG智能问答系统

---

## 第一步：环境准备（2分钟）

### 1.1 安装 Ollama

1. 打开浏览器，访问 [ollama.com](https://ollama.com/)
2. 下载 Windows 版本并安装
3. 安装完成后，打开命令提示符（CMD）或 PowerShell

### 1.2 下载模型

在命令提示符中依次运行：

```bash
# 下载大语言模型
ollama pull deepseek-r1:7b

# 下载嵌入模型
ollama pull nomic-embed-text
```

> 提示：如果下载速度慢，可以考虑使用 qwen2:7b 或更小的模型

---

## 第二步：配置项目（2分钟）

### 2.1 安装Python依赖

在项目文件夹中打开命令提示符，运行：

```bash
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

### 2.2 测试连接

```bash
python test_ollama.py
```

如果看到"测试成功"的提示，说明环境配置正确！

---

## 第三步：开始使用（1分钟）

### 3.1 启动应用

双击 `启动应用.bat` 文件，或者在命令行运行：

```bash
streamlit run app.py
```

浏览器会自动打开应用界面。

### 3.2 上传文档

1. 点击左侧侧边栏的"上传文档"
2. 选择 docs 文件夹中的示例文档，或者上传你自己的PDF/DOCX/TXT文件
3. 点击"构建知识库"按钮

### 3.3 开始提问

1. 在底部输入框中输入问题，例如：
   - "什么是自然语言处理？"
   - "NLP有哪些应用领域？"
   - "Transformer是什么？"
2. 按回车发送，查看AI的回答！

## 常见问题快速解决

### 问题：提示"Ollama服务无法连接
**解决方法**：
1. 检查Ollama是否已安装
2. 打开任务管理器，查看Ollama进程是否在运行
3. 尝试运行 `ollama serve` 手动启动服务

### 问题：模型下载太慢
**解决方法**：
1. 检查网络连接
2. 尝试使用更小的模型，如 `qwen2:1.5b`
3. 可以在夜间网络好的时候下载

### 问题：回答质量不高
**解决方法**：
1. 确保上传的文档内容要清晰、结构化
2. 可以尝试调整问题的表述方式
3. 增加更多相关文档到知识库
